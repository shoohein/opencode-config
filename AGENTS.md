# Root Instructions

This repository is the machine-local OpenCode configuration at `$HOME/.config/opencode/`. Files here are loaded as global settings, not per-project overrides.

- `agents/` — global subagent definitions
- `instructions/` — global instruction modules
- `skills/` — global skills
- `opencode.jsonc` — global config

## Style

- **Match abstraction level when listing items**: Each entry in a list should be at the same abstraction level. Do not mix high-level concepts with low-level implementation details in the same list.
